# Icon-generation protocol

## Source page 4

ICON GENERATION PROTOCOL — APPLY TO EVERY ABILITY
 Generate an individual original pictorial ability icon for EVERY catalog entry below. Icon artwork is not a stock icon or an emoji:
 paint a polished high-fantasy miniature illustration like the example references. Each image must immediately communicate its
 actual power (running figure with long speed streaks for super-speed, not an unrelated glowing orb).

 IMAGE SOURCE: create at 1024x1024 square PNG with transparency; keep all important content in the central 80% safe area.
 Paint at high resolution, then produce 256x256 menu texture, 64x64 quick-slot texture and a 32x32 readability-check thumbnail
 (retain originals). Use premultiplied-alpha-safe edges. Do not place words or numbers in the image. Build badges, rank or mode
 labels as GUI overlay text rather than baked pixels.

 VISUAL TEMPLATE: central recognizable subject occupies around 65% of the image, dramatic inward converging particles or
 motion trails, silhouette readable at 32 px; layered glow gives depth but does not obscure shape. Outer restrained ornamental
 square frame with small corner engravings, metallic silver for common, violet for unique, gold for ultimate, and deep
 amethyst-gold for sovereign. A frame must not disguise the unique motif.

 PER-ABILITY SPEC: each brief below contains an explicit central subject/effect action derived from that entry’s description, with
 distinct ornament/energy language and palette rules. The text is a GENERATION PROMPT, not a guarantee that images have
 been generated. A coding agent must actually render, inspect, resize and register each file.

 NAMING: use assets/jaycee/textures/gui/abilities/<ability_slug>.png for the 256px version and
 assets/jaycee/textures/gui/abilities/hud/<ability_slug>.png for the HUD. A canonical icon_id points to them from the ability
 registry; advanced modes may have extra overlays or distinct variants but cannot silently replace the base identity.

 ACCEPTANCE: visually compare each texture to its brief at full size and 32px; reject wrong silhouettes, duplicate-looking
  abilities, illegible blurry glows, oversaturation or opaque background. The concept art preview can be larger and more scenic, but
  it must visibly relate to the same motif as the icon. Alt+slot changing mode updates the mode indicator and any explicitly
 mode-specific icon overlay without casting.
