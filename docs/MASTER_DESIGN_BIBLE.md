## Source page 43

JAYCEE  : DI IMMORTALES

SYSTEM ARCHITECTURE


How the system works





  ABILITY RANKS

    Intrinsic and Common → Extra → Unique → Ultimate → Sovereign Authority. Evolutions

   and rare rewards unlock higher tiers.





  LEARNING & MASTERY

   Earn Learn Points to acquire skills. Use learned skills to gain Mastery; advanced

   modes, lower cooldowns, and stronger scaling unlock later.





  ABILITY INPUTS

    Press, Hold, Toggle, In-Slot Passive, or True Passive. Alt + slot key cycles modes;

    Alt + mouse wheel cycles ten four-slot pages.





  CLASS IDENTITY

   Twelve origin classes, optional secondary paths, innate race pools, battlewills,

   magic schools, and the restricted Jaycee sovereign path.





  UI PRESENTATION

   Show name, rank, illustration, cost, cooldown, mastery, tags, ability modes, and

    status. Use separate overlays for locked, mastered, and active.





  IMPORTANT SCOPE

   This document specifies intended behaviors. It is not evidence that the listed

    abilities have been coded, balanced, or tested in Minecraft.
