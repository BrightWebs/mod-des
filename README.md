# Jaycee: Di Immortales — GitHub-ready agent handoff

This package converts the available **92-page master PDF** to searchable Markdown, JSON and reference PNGs. It is a **specification**, not a completed Minecraft mod.

**Start at [`AGENTS.md`](AGENTS.md).** First UI design instructions: [`docs/GUI_DESIGN.md`](docs/GUI_DESIGN.md).

- Extracted icon entries: **292**.
- Individual icon prompts: `data/icon_descriptions.json` and `docs/ICON_DESIGN_GUIDE.md`.
- Ability metadata: `data/abilities.json` (undefined balancing values are `null`).
- Encyclopedia: `docs/MASTER_DESIGN_BIBLE.md`.
- Actual reference artwork: `references/`.

Copy this folder's **contents** into the root of your existing GitHub repository on a new branch; do not replace mod source files. The examples are style references, not icons already built.
